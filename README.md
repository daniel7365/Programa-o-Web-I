
# 📄 Currículo Web — Disciplina de Programação Web

> Projeto desenvolvido como atividade prática para a disciplina de **Programação Web** do curso de **Engenharia de Software** da **Universidade do Estado do Pará (UEPA)**.

---

## 📌 Sobre o Projeto

O objetivo deste projeto é a criação de um **Currículo Online (Web Resume)** responsivo, apresentando informações acadêmicas, experiências profissionais, projetos desenvolvidos e habilidades técnicas. 

A atividade busca consolidar os conceitos fundamentais do desenvolvimento web *front-end*, com foco na estruturação semântica, estilização e boas práticas de código.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização, layout flexível (Flexbox / CSS Grid) e responsividade.
- **JavaScript** *(opcional)*: Interatividade e efeitos dinâmicos na página.
- **Git & GitHub**: Controle de versão e hospedagem do código fonte.
- **GitHub Pages**: Publicação e hospedagem online do projeto.
